## 结论与适用范围

**已将主要误差入口定位到“真实伪距相对当前物理预测/大气假设的失配”。保留真实伪距、替换载波和多普勒后，完整高差仍为+8.968 m；保留真实载波和多普勒、替换伪距后为−0.404 m。载波侧真实失配并不是本次正9 m高差的主要入口。**

这是一项受控诊断：替换值由已知参考位置和当前产品生成，不能部署为真实观测改正，也不能声称真实PPP精度已提高到0.4 m。结果尚不能把所有码侧失配进一步唯一归为手机硬件、卫星偏差产品或单频电离层绝对偏差。

大气项获得了独立于滤波状态的核查：验证弧中，实际GIM变化与真实相位变化基本相符，而码侧仍有约7.4 m未解释变化；全部观测的共同干/湿延迟自由拟合也不能解释主要时间变化。由此不能再将所有现象笼统归为“电离层没消除”或“换卡尔曼更新公式”。

正式PC/Android源码、默认R/Q/P0、GIM、抗差、Joseph及APK均未修改。用户参考坐标维持30.69820588888889°、104.05203827777777°、椭球高459.813 m，已确认与手机同高。

## 2. 将GIM变化与码相变化分开

不使用滤波估计电离层，在已验证的C19/C20、B1I/B2a连续弧187～324历元进行：

`C = (P_5P−P_2I)_C19 − (P_5P−P_2I)_C20`

`L = (L_5P−L_2I)_C19 − (L_5P−L_2I)_C20`

`G = (gamma_5P−gamma_2I) × (I_GIM,C19−I_GIM,C20)`

原始相位按实际波长转米，使用当前SSR码偏差、天线及相位缠绕改正。共276次独立native产品查询取得固定参考位置、实际方位/高度角下的捕获GIM延迟，不使用滤波I状态。连续弧首点允许重启，其后没有跨越slip/reset、缺测或毫秒时标变化。

### 为什么单频绝对电离层与未知码偏差仍不能从同一数据唯一分开

以斜向L1电离层为I、频率系数为gamma，观测写作：

`P = common + gamma*I + bP`

`L = common − gamma*I + N`

在同一连续弧内，变换

`I' = I + a, bP' = bP − gamma*a, N' = N + gamma*a`

给出完全相同的P和L。这里a是弧内常量斜向偏移；对应垂直I可随映射变化。若允许未知逐星/逐频码偏差，观测自身不能唯一选择这一族解。GIM、产品码参考及硬件校准假设决定其基准。

这说明剩余限制是明确的观测可辨识性，不能仅靠重复读取相同残差解决，也不能无约束增加每星自由码偏差状态。当前模型没有估计自由逐星码偏差；该变换是在说明“潜在物理来源的归属”为什么尚不唯一，并非宣称正式设计矩阵全部严格秩亏。
