# 起始码差与后续变化的独立分离

日期：2026-10-28。沿用当前小米、同一WHU实际录流、官方ANTEX、AUTO IONEX几何及B_VERIFIED_v2_JOSEPH非组合路径。

**本次新增证据：仅保留各卫星／信号首个样本的码模型差，末期高差仍为+11.288 m；仅保留后续变化时为−2.648 m。该分解下，后续变化部分反而补偿起始码差的正高差作用。**

这解释了上一轮因果漂移Huber为何只带来约1.7 cm变化：它不能识别弧段起点已经存在的基准项。但首样本差包含瞬时噪声、GIM／中性大气或其他物理预测误差与码参考差，不能认定为真实恒定硬件偏差，也不能据此直接标定或修复手机。

## 实验定义

复用已保存的15242条真实码和参考前向模型码，不下载新产品、不改R/Q/P0或抗差参数，不重新执行旧删星／阈值试验。

对35个实际卫星＋信号键，定义：

`d_s,f(t) = P_real(t) − P_model(t)`

`d_initial = d_s,f(first_actual_sample)`

`d_later(t) = d_s,f(t) − d_initial`

首样本只取该信号首次实际出现的一个值，不用未来平均、不搜索最优起点。不随载波周跳重新定义码基准，以分开码历史和相位弧段生命周期。

独立输入分别为`P_model+d_initial`、`P_model+d_later`。真实L/D、未建模槽和质量标记保持原样。原码重建与零码差控制直接复用已验证的旧回放，不重复运行。首历元缺失参考行G32/1C继续在所有组保留真实值，不插值或补零。

**该实验使用已知参考位置构造模型码，只有诊断意义；不是真实自主PPP精度提升，不是可部署的初始校准。**

## 应如何解释

1. 从各信号初现时就携带的码模型差，足以在本段联合估计中维持大正高差；仅处理后发漂移不会消除这个分量。
2. 后续变化不能忽略：即使移去首样本差，后期仍出现约−2.65 m高差。首样本单点校准并不能保证后续稳定精度。
3. 这里检查的是**观测相对模型的码差起点**，不是SPP位置状态初值。此前“仅替换初始位置均值不能解决主高差”的结论仍有效，不应回头重做同一个位置初始化试验。
4. 暂不能把首样本差分配为手机硬件、卫星码产品或单频电离层绝对偏差。当前采集包只有手机观测、录流和产品，没有同期测量型接收机观测；用户后续已明确确认没有同期参考接收机RINEX。
5. 未发现新的确定正式代码错误。本轮不按真值扣码、不调R/Q、不给全部卫星无约束增加码偏差状态。
