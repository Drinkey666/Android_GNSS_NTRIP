# M1_v4 单频和双频首码对照

沿用第五轮保存的六组正式基线。隔离构建补跑六组第六轮 A 和三档 M1_v4 各六组。工作目录仅修改私有 ppp 和 rtkcmn 副本，正式代码延续非组合、显式电离层及浮点模糊度。B/C 未重跑。全部参考坐标只用于解后评价与投影。

## 结果

- 11:20 vivo，A 的全段 H/U RMS 为 1.177/1.904 m，std、tight、sf_only 对应 1.207/1.828、1.216/1.789、1.204/1.811 m。三档高程均改善，水平全段均反退。G03 1C 的首 20 期高程贡献从 A 的 −2.719 m 降到 tight 的 −1.654 m，水平向量模由 1.318 m 降到 0.777 m。
- E27 1C 全段三档均未触发，A、std、tight、sf_only 的最大偏离/门限比分别为 0.994、0.918、0.992、0.923。C19 2I 的 6/8/6 次触发全部发生在前 60 个 Q6 之后，触发均值为 1.06/1.21/1.08 倍，初段下拉反而大于 A。
- 10:04 小米的 G28 1C 在 std/tight 下全段触发 31/60 次，前 60 期两档均为零。std 的全段 H/U RMS 为 2.094/2.810 m，sf_only 为 2.097/2.755 m。允许所有双频首码降权仅带来约 3 mm 的水平 RMS 变化，高程 RMS 增加约 5.5 cm。这个对照的开关覆盖所有双频首码，G28 的单星因果作用无法从中隔离。
- 10:04 小米的三档 H/U 均高于 A 的 2.010/2.703 m。11:20 小米的三档全段 H/U 亦均高于 A。10/31 V2，std/tight 的末段 H/U 低于 A，但全段 H/U 上升。此次保留 A 为诊断对照，三档归档为 NEGATIVE_NOT_FIX。

## 口径

- std/tight/sf_only 只对参考槽进行检验。GIM 可用时单频码用系数 1.0，双频首码用 0.5。四颗双频星起用半和中心，其余采用全组中位数。MAD 统一按全部参与卫星相对最终中心的绝对偏差计算，每星一票。
- tight 的无相位单频仍按 MAX(2.0,1.8×scale)，仅随 tight 上限 1.5 一起变化。sf_only 保留双频星的半剥离、中心和 MAD 作用，只禁止该类首码方差膨胀。两档对照检查的是是否允许双频首码降权。
- 触发次数统计最终成功 Q6 的码行。平均倍率只对实际膨胀行计算。前 20/60 指各方案的前 20/60 个 Q6。水平推力用累计 E/N 向量及其模表示，高程用累计 U。CSV 同时给出相对 A 的差值。

## 核验

24 组新回放的 Q 序列、观测及 SSR 改正均与已保存正式基线一致。六组 A 除处理耗时外逐字段复现，状态文件逐字节一致。核验 216 项历史和正式文件。成功提交的 ECEF K·v 闭合误差最大 4.66e-10 m，检查 176,940 条非参考码行全部保持新增倍率为 1。逐组核对参与星数、双频星数、中心、MAD 尺度和最终方差倍数。
