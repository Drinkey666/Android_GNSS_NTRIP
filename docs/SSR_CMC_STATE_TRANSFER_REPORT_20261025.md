# C06 连续码相失配的状态传递与记忆：定点追踪

## 本轮确定到什么程度

已把一段实际持续失配追踪到：**C06 B1I 码方程 → 同次增益 → 高度/公共钟差/BDS ISB/逐星电离层/模糊度 → 后验提交 → 下一历元预测 → 后续数百秒残留**。这是同一实测数据上的状态传递和局部因果证据，不再是“某个状态相关系数较大”的推测。

保留原始 P 用于卫星位置、预处理和模糊度初始化，只在 PPP 更新方程停用 C06 B1I 码行 31 秒；该段载波仍有 31 条，弧段无重置。窗口结束时相对原解：Up −1.170201 m，公共钟差 −0.986179 m，BDS ISB −0.174273 m，C06 垂直 L1 电离层 −0.178605 m，ZTD +0.006253 m，模糊度 +0.628472 m。恢复该码行后，末历元仍有 Up −0.365583 m 差异。

**还没有证明 C06 原始码本身错误，也没有解释全部约 9 m 高程误差。** 这里确认的是该码方程的持续失配怎样推动实际状态；其起源仍可能包含码/相误差、真实电离层与所用先验不匹配等。没有发现新的确定公式/单位/索引错误，本轮不修改正式算法。

## 必须更正的上一轮实验归因

上一报告将“在 PPP 输入将 C06 唯一码置零”的全程结果作为对照：末点 Up 9.0672→6.7584 m。**它不是严格的只删除一个码测量行的实验。**

具体代码是 core/ephemeris.c:895 的 satposs()：先在 NFREQ 中寻找任一非零 P 计算发射时刻；全部 P 缺失时打印 `no pseudorange` 并跳过卫星。pppos 在 core/ppp.c:4640 调用该函数，早于状态更新。因此输入 P 置零不仅改变模糊度播种，还使 C06 载波失去卫星位置而无法进入方程。

本轮输入缺码窗口的 trace 已复现 `no pseudorange ... sat=101`。从重建后一历元才开始缺码，载波同样退出，并在 30 秒后触发既有 OUTAGE 重置。这不是“之前的旧弧段复活”错误，也不能靠在实验里保留 L 字段就宣称载波保留。

所以，原 2.3088 m 全程末点差应称为 **C06 输入缺码及其连带模型/载波变化的联合效果**，不可全部归给码行单独贡献。原始数值、文件与命令仍保留；本轮严格 ROW_ONLY 实验替代其用于码行归因。原单步固定先验、明确只移除码行的矩阵实验不受该勘误影响。

## 1. 固定追踪范围与观测定义

仅复用 validation/android_long_20261025/imported 的同一包 701 历元、WHU 流及冻结预报大气。参考坐标仍是用户提供的 WGS84 30.69820588888889°、104.05203827777777°、椭球高 459.813 m，仅解后使用。

追踪窗口为 GPST tow **22336～22366，31 个 1 Hz 历元**，即 PPP 更新序号 130～160。起点刻意置于 22335 已确认的弧段重建之后；窗口内基线没有再次重置，也没有缺历元。未重新做 CN0、全项目物理项、P0/R 消融或卫星组合搜索。

实际非组合方程，见 core/ppp.c:3645、3672：

```
P* = rho + clock_GPS + ISB_BDS - c*dt_sat + trop + gamma*mapf*I_vertical + RCB
L* = rho + clock_GPS + ISB_BDS - c*dt_sat + trop - gamma*mapf*I_vertical + N
```

I_vertical 是参考 GPS L1 的垂直延迟，单位 m；gamma=(f_L1/f_signal)^2，mapf 无量纲。C06 使用 B1I/2I，接收机的该参考码偏差由钟差/ISB 表达，不存在一个专门表示 C06 随时间变化码偏差的独立状态（ppp_ifb_index，core/ppp.c:261）。N 为米，不能与周数混用。

保留非组合框架。P−λL 中共同几何/钟差/对流层可消去，但双倍电离层、码相硬件、相位异常不会消失；不能把它直接命名为纯码误差。

## 2. 同次更新实际把失配放到了哪里

每个 trial 保存只读 FILTER_INPUT、TRIAL_POSTERIOR 和 COMMITTED 的目标状态；从实际 K 记录所有真实码、相位、IONEX 和 VMF3 约束行对这些状态的更新。只取最终提交的 trial；不累计被编辑失败的试更新。

窗口内 C06 码行 pre-fit v：均值 **+10.01995 m**，范围 +6.21449～+12.09885 m，31/31 同号；相邻新息描述性相关系数约 **0.99657**。不将 31 个点当作 31 个独立样本作显著性检验。

该码行在实际轨迹中的 K_i v_i 累计：

| 状态 | 31 历元 C06 码行累计更新 |
|---|---:|
| Up | +1.234212 m |
| 公共钟差（米） | +1.045001 m |
| BDS ISB（米） | +0.214089 m |
| 总 ZTD | −0.005517 m |
| C06 垂直 L1 电离层 | +0.186877 m |
| C06 B1I 模糊度（米） | −0.669256 m |

这些数值是不同状态的更新，**不能相加称为对 10 m 新息的“吸收百分比”**。只有乘回各自在观测方程中的 H 系数，才能比较预测观测值的变化；位置应先投影到该星视线，而不是直接把 Up 相加。

例：更新序号 160，v=12.077319 m：

- 该码行使 Up +0.042997 m，公共钟差 +0.036453 m，BDS ISB +0.007499 m，I_vertical +0.006621 m，N −0.023060 m。
- 乘回码方程后：几何 −0.007489 m，钟差与 ISB 合计 +0.043951 m，对流层 −0.000430 m，电离层 +0.011684 m。该码行自身的影响约为 0.04772 m，远小于原始 12 m 失配。
- 所有行更新后的该码线性残差仍约 +12.029857 m。因此不是“一次滤波把 12 m 都吃进电离层”；它每秒留下大部分失配，同时反复给高度和钟差一个同向小增量。

在该 31 秒实际窗口中，所有观测行对 C06 电离层的更新合计 +0.168940 m：C06 码 +0.186877 m，C06 电离层先验 −0.029781 m，其余行部分抵消/补偿。该星 I 从 9.868807 变为 10.037747 m，形式标准差却从 0.125294 降到 0.112474 m。不能将这种收紧当作实际系统误差变小。

完整分组账本：validation/ssr_cmc_transfer_20261025/window_state_transfer_budget.csv。每个历元所有分组 K v 之和与实际提交状态增量闭合，最大误差小于 3.73e−9 m。

## 3. 为什么现有判断没有阻止这段持续失配

此处只追踪已确定的窗口，不进行新阈值选择。

- apply_legacy_robust_ppp（core/ppp.c:3298）按单点 z0 超过既有 4σ 才增加当前残差处罚。
- reject_postfit_ppp（3314）按既有 8σ 验后拒绝。
- 本窗口的最大验后 |res|/sqrt(R0) 约 **2.418**，没有达到这两个门限。实际 R 与基础 R0 的差异已保存，不能将 R-only 值冒充新息 S 标准化。
- 每个点单看不极端，但持续同号、强相关。当前码行没有一个可单独辨识的时变偏差状态，逐点抗差与现有状态模型未把这段持续失配分离出来。

这不是建议把 4σ/8σ 调小，更不是建议把这段全当随机噪声放大 R。相同表现也可能来自电离层/其他状态先验失配，来源判别仍需保留。

已知 B 模式 GIM 每秒约束的语义不在本轮重做消融：当前 -IONCONSINT=1，ion_constraint_interval（2372）并不自动采用产品的小时相关尺度；先验行在 ppp_res（3830 起）加入。保存的第 179 次更新 C06 IONEX 行 R=2.25 m²、v=−0.397638 m。它与历史相位等信息共同约束电离层。**未单独改变该先验，不能把本轮方差收缩或高度误差全部归因于 GIM 重复使用。**

## 4. 严格码行实验与后续记忆

独立诊断配置 ROW_ONLY：原始 P/L、satposs、预处理与状态初始化均保留，仅在 ppp_res 形成观测行时，于 22336≤tow<22367 跳过 C06 B1I 码方程。相位方程和原有大气约束保留；窗口结束立即恢复码行。正式 core、默认参数与安卓 APK 不改。

验证：

- 干预前所有目标状态完全相同。
- 窗口内仅这条码行不参与，C06 相位与先验各保留 31 条；C06 arc reset=0。
- 首个受影响历元的完整状态差，与“相同预测先验删除一个码行”的线性反事实最大差仅 **1.31e−9 m**。

### 记忆在源码中怎样留下

1. **提交：** pppos（core/ppp.c:4928）将成功 trial 的 xp/Pp 一次性复制进 rtk->x/P。该段不是失败矩阵污染或试算重复提交。
2. **高度：** udpos_ppp（2153）在当前 STATIC 模式保留位置均值，只作既有过程方差传播；因此已形成的高度偏移会作为下一期预测位置。
3. **电离层：** udiono_ppp（2456）按观测连续性保留同星电离层，增加既有 Q；不会因某次码新息大或某个载波重启而清掉整个 I。此处未发现生命周期错误。
4. **钟差与 ISB：** udclk_ppp（2239）重置公共钟差协方差到原 VAR_CLK，但均值起点仍取上一可信 PPP 钟差，之后重新对齐公共钟差；BDS ISB 均值跨历元保留。重置钟差 P 并不等于清除其他联合状态的记忆。公共钟差绝对值还含正常接收机漂移，本报告只比较同次更新及两条相同输入轨迹的差，不把约数百米/秒的绝对钟差变化当本异常。
5. **模糊度重建：** udbias_ppp（2648、2863）在后续确认周跳时只清该弧 N/P 并从当期码相、电离层重新播种。第 161 次预测中，两条轨迹的模糊度差从约 +0.628 m 变成 −0.630 m 的新 seed；同次更新后又为 +0.619 m。与此同时 I/钟差/高度差仍在，所以重启 N 不会自动撤销联合状态偏差。这是当前状态定义下的正常传播，不能为了去掉偏差而把全部 PPP 状态清零。

## 5. 检验、交付与界限

独立观察程序的 H 仍为 nx×nv。原更新不改；诊断对角 R 条件下的单行边际影响使用：

```
a = h_j' K_j
e_plus_j = v_j - h_j' K v
x_all - x_without_j = K_j * e_plus_j / (1-a)
```

只有 R 对角且分母数值有效才给出该量。另输出原 Sjj=h_j'P⁻h_j+Rjj，及条件方差 Rjj/(1−a)，两者字段严格分开。用上一轮已保存的 5 个有 C06 码行的完整矩阵，以直接线性求解删除行后更新逐状态核对该恒等式；未使用伪逆或正则化，也未替换正式求解器。

本轮检查：

- baseline 全部 701 历元除实测 processing_ms 外与既有基线完全相同；state/obs 文件逐字节相同。
- baseline 及三个有界窗口实验各 701 历元，均 223 Q0、1 Q5、477 Q6。
- 分组状态更新闭合、单行恒等式、首期严格反事实一致性全部通过；正式 ppp.c/rtkcmn.c/rtklib.h 前后哈希一致。
- 诊断初版 CSV 将 North 与 ambiguity 都命名为 N，已按原固定列序改成不同字段；数值正文没有修改。diagnostic_header_repair.json 保存正文哈希，分析器强制检查所有字段名唯一。这是诊断输出命名修正，不是正式滤波器状态索引错误。
- 没有重新运行并冒称通过此前全部 native/JVM 测试；本轮没有修改这些测试对应的正式算法。当前新增检查与探针构建结果独立留档。

主要文件：tools/ssr_cmc_transfer_probe.c、tools/run_ssr_cmc_transfer.py、tools/analyze_ssr_cmc_transfer.py。证据目录 validation/ssr_cmc_transfer_20261025/，入口 analysis.json、source_provenance.json、window_state_transfer_budget.csv、selected_state_memory.csv、causal_state_memory.png、window_transfer_budget.png。所有重放共用原始产品，不生成新的产品副本；大诊断日志无损压缩后保留，可用脚本复查。

### 当前可落实的判断

**已证实的问题机制：** 持续、同向且相关的码方程失配没有被当前逐点判断分离，进入联合状态并在 STATIC 预测、ISB/电离层连续性与模糊度重建中留下记忆。形式协方差同时继续收紧。它解释了本段一部分漂移如何形成和为何不会立刻消失。

**不是本轮找到的新软件错误：** 卫星几何缺码时退出、正确周跳后的 N 重建、公共钟差白噪声协方差重置、只提交成功后验等均按现有实现运行。尚没有依据改正某个符号、索引或清零整个滤波器。

**下一步范围只需围绕这一入口：** 对“持续失配”同时检验观测偏差证据与状态/外部先验失配，避免把真电离层变化直接当坏码；验证应使用本次 ROW_ONLY 保留几何/相位的隔离方式。不能直接固定屏蔽 C06、降低 4σ/8σ、任意扩大 R/Q，或宣布只换抗差函数就能解决全部米级误差。本轮没有启用任何新的抗差、自适应或默认屏蔽。
