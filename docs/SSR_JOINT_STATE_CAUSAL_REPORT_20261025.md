# WHU 实际手机包：北斗恢复后的高度偏差定位

## 后续勘误：输入缺码与只停用码行不同

后续 [C06 状态传递报告](SSR_CMC_STATE_TRANSFER_REPORT_20261025.md) 已确认：本报告的全程“C06 P 置零”实验同时使 satposs 因无伪距而跳过该星，载波也退出。因此 9.0672→6.7584 m 的末点变化是输入缺码及其连带载波/模型变化的联合效果，不能全部归为码行单独贡献。本报告原始数值保留。新的严格 ROW_ONLY 实验保留原始伪距、几何和全部31条C06载波，只停用31秒码行；窗口末Up差−1.1702m，恢复后末期仍−0.3656m。原单步矩阵“只移去码行”结果仍有效。后续归因以新报告为准。


## 结论与范围

延续 SSR_BDS_FIX_AND_REPLAY_REPORT_20261025.md，不重跑旧 P0/R 消融、不调 R/Q/P0/GIM/抗差阈值。本轮没有改正式核心源码，没有构建或安装新 APK。

已进一步确认 **C06 B1I 伪距在本段存在持续的高度推动作用**。独立全程停用这一个码观测后，末点 Up 从 +9.0672 m 变为 +6.7584 m，末 60 个 Q6 历元 Up RMS 从 9.1725 m 变为 6.7508 m。该结果支持局部因果影响，不证明 C06 永久无效，也不能解释剩余 6.76 m 偏差。初期部分时刻反而更差，不能据此宣布通用算法改进。

同时发现实际联合状态对高度的约束很弱：后期高度—公共钟差相关系数约 0.94，高度—ZTD 相关系数约 −0.69。这说明码/电离层/钟差/模糊度/高度之间能分摊偏差；**不是已经证明其中哪一个物理公式写错**。

本轮没有新增足以直接修改正式模型的确定公式、单位或索引错误。此前已证实的现代 BDS SSR 解码修复保留，不能恢复错误解码来获得较小高程误差。

## 4. 可以排除哪些共同物理项

直接从进入 PPP 的未平滑观测计算 C06 B1I P−λL。在没有缺历元、没有记录 LLI 周跳且没有半周不确定标志的连续段中，仍见：

- GPST tow 22335～22366，32 个样本，净变化 +8.6502 m，跨度 9.4323 m。
- GPST tow 22461～22485，25 个样本，净变化 +14.5828 m，跨度 14.6132 m。

这些数值不依赖参考坐标或 SSR 改正。P−λL 会消去同频共同的几何距离、接收机钟差、卫星钟差及一阶共同对流层项。它不会消去双倍一阶电离层、码/相硬件变化、码多路径、相位异常或漏检周跳。因此，**该相对变化不能仅由 SSR 轨道或共同钟差一项解释，但不能据此断言真实电离层或原始相位一定无异常**。

在 22335～22366 段，实际应用的 SSR C06 码偏差始终 +2.7000 m；卫星天线改正变化仅约 0.000034 m，phase-windup 变化约 0.000392 cycle。滤波估计的 L1 斜向电离层变化约 +0.3314 m，不能在当前已估状态中解释全部约 8.65 m 码相变化。该码相变化也不是本次偏差消息切换制造的跳变。

载波增量与梯形积分 Doppler 的差值 RMS，在上述两段分别约 0.120 m、0.196 m；并非完美无噪声相位证据。故只确认码/相/模型相互失配，不强行将它归因到某个未观测硬件项。相关性和可辨识性限制保留。

逐行实际公式仍为 core/ppp.c:3672：

`res = corrected_observation - (geometry + receiver_clock - c*satellite_clock + trop + iono_coefficient*iono + receiver_code_bias + ambiguity)`

卫星/接收机天线及 phase windup 在 corr_meas（core/ppp.c:1150）转入改正观测，SSR 码偏差只加一次；Doppler 平滑差值在 applydoppsm_ppp（1491）另加。日志记录了这些分量及固定参考位置的 geometry/trop/iono。

214,350 条方程记录重建误差为零，证明记录与实际程序方程闭合、没有混淆 pre/post；**这是同一程序分解的闭合，不是独立证明每项物理模型都正确**。固定参考位置的残差保留原钟差、RCB、逐星电离层和模糊度，不将其误称为“钟差已知的真值残差”。

## 5. 联合状态为何容易保留高度偏差

后验位置块旋转到 ENU，再取归一化相关系数，避免直接比较不同尺度矩阵条件数：

| PPP 更新序号 | 估计 σUp (m) | corr(Up, common clock) | corr(Up, ZTD) |
|---:|---:|---:|---:|
| 179 | 0.548 | +0.937 | −0.548 |
| 299 | 0.456 | +0.933 | −0.622 |
| 477 | 0.384 | +0.942 | −0.687 |

最后约 9 m 偏差远大于形式 σUp≈0.38 m，说明该段形式协方差不能覆盖实际位置误差。它不等于 Joseph 又失效；Joseph 保证数值协方差有效，不保证随机模型包含所有系统误差。

另做**单历元真实码行**的结构诊断：以实际 R 白化，消除自由钟差/ISB、RCB、逐星电离层和 ZTD 等非位置列，使用列归一化及秩揭示 SVD 分析剩余位置列。未以 SVD 或伪逆替换任何正式滤波求解。

后期 28 条真实码行，消去非位置状态后仅剩 5 个观测空间维度；残余位置设计阵奇异值约 0.1280、0.0946、0.00282 (1/m)。1 m Up 扰动在重新拟合这些自由非位置状态后，最小加权失配范数仅 0.00922。这说明**单历元码数据自身对高度很弱**。

这里没有包含跨历元模糊度连续性、状态预测或外部先验，因此不能把这个指标当成完整 PPP 不可观测的证明。它说明为何“有许多卫星/小相位残差”不足以证明高度正确，完整结果高度依赖已有弧段及大气/码偏差参考的一致性。

相关实际函数：ppp_ifb_index（core/ppp.c:261）、udclk_ppp（2239）、udiono_ppp（2456）、model_iono（3033）、ppp_res 电离层与 RCB 偏导（3647～3662）。没有在这些位置试探性改参数。

## 6. 分类与下一步最小范围

**已经证实：** C06 码行对这段高度曲线有持续影响；码相相对变化不由共同轨钟项单独造成；实际状态存在强高度—钟差/ZTD 耦合；同次矩阵及只读日志没有造成解算分叉。

**尚未证实：** C06 真实电离层、未建模码/相偏差、漏检相位异常各占多少；剩余 6.76 m 来自哪些独立项；当前单次 478 秒 PPP 段是否能代表其他时段；C12 非零 IF 码偏差是否错误。本轮没有据此归一化 OSB 或调整时标。

**下一步最小范围：** 优先验证“连续码相失配是否会作为白噪声被反复提交，且被钟差/逐星电离层/高度吸收”的处理路径：只针对已保存 C06 连续段，在统一物理状态下核查码/相差变化和现有偏差/弧段状态能否表达。随后用未参与选择的新时段验证通用处理，不能将本段停用 C06 作为新默认。保留非组合框架，不以改成 IF 或调 Q/R 代替归因。

本轮没有找到可立即正式修改的新确定代码错误，故正式算法不改；精度问题仍未解决。新版 APK 仍未安装，手机继续保留已采集版本。既有 634 native / 35 Python / 132 JVM 测试是上一轮结果，**本轮不虚报重新运行全部测试**；本轮验证为独立探针构建、两次 701 历元只读/因果回放、同次求解检查及上述输出一致性检查。
