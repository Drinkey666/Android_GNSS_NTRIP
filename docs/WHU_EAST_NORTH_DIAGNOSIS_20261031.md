# 东向/北向分离分析与问题收窄（2026-10-31）

本轮复用三组已完成的669期启动策略回放，不重新构建或回放。只新增只读分析工具、图和诊断表，未修改坐标、参考、原始输入、PPP/SSR/Android代码及任何参数。

## 1. 方向定义与比较方法

参考仍是本次采集包内的WGS84纬度30.767151638888887°、经度103.97950708333333°、椭球高483.98m。E正为向东，N正为向北；负N表示偏南。逐期验证H²=E²+N²，不将水平误差均分到两个方向，不通过真值回调模型。

仅统计Q6。Q5/WAIT不混入RMS；曲线在Q5处断开。重点使用相同末60秒（采集约609～668s、各60个Q6）比较，避免将原组冷启动84期与首份组全663期直接当作同一窗口。

在首份诊断组，东向从初期约+1.25～+1.9m缓慢趋于+1.48m；北向从约−2.1m趋于−0.82m。末段两个方向均同号，标准差很小但均值明显偏零，表现为**稳定的东南向偏置**，而不是主要由随机跳动造成的RMS。小标准差不等于真实精度高，也不表示历元独立。

## 3. 卫星几何不能单独解释三组差异

逐期核对同一末60秒，三组的**已用载波卫星、频率槽掩码和输出方位/高度角全部60/60一致**。因此三组末段E/N差异不能简单归结为换了一套卫星分布。

仅用LOS、每个在场星座一个钟参数、单位观测方差构造几何诊断，QR满秩求解得到三组相同的平均几何指标：E约0.764、N约0.652、U约2.024，东/北比约1.17。未使用伪逆或正则化。它只说明该简化几何下东向略弱，**不包含实际R、P、电离层、模糊度或对流层联合估计**，不能当作PPP可观测性/后验精度，更不能直接认定1.48m就是几何造成。

不同启动历史仍会改变状态、协方差和原有残差处罚，即使输入卫星相同，也不保证K/R有效值相同。现有stat仅保存XYZ协方差对角，缺少交叉项，本轮没有把它错误旋转成E/N置信区间。

## 4. 状态关联：存在耦合线索，没有独立因果归因

读取pppoutstat实际字段：$CLK单位ns，转换到米；$TROP为总ZTD；$RCB/$ION及$SAT中模糊度为米。所有组同一状态定义，不混用旧PHYSICAL湿改正量。

首份相对原组末60秒，平均差值：

- ΔE=+0.478m，ΔN=+0.690m，ΔU=−0.038m；
- Δ总ZTD=+0.116m、Δ公共钟差=−0.346m、ΔBDS ISB=+0.177m，部分RCB和逐星I也变化。

这说明启动改变后，位置与其他状态落在不同的联合解上，不能将某一状态的差值直接当成E/N误差贡献。

在共有585～668秒窗口，首份组E与E10电离层状态的相邻历元变化相关约−0.840；N与GPS C5Q接收机码偏差状态的相邻变化相关约+0.804。已同时保存原序列及不跨缺失/Q5的连续一阶差分相关。**这些状态来自同一滤波更新，相关性可能是共同驱动或状态补偿，不证明E10电离层/GPS RCB实现错误。** 不按相关系数调整参数，也不把I估计当独立电离层真值。

## 5. 从已存残差记录收窄到具体观测，避免误判

先核对实际输出含义：`core/rtkpos.c::rtkoutstat()`（76起）的$SAT包含残差及载波vsat；它没有独立的最终码接受标志。`core/ppp.c::ppp_diag_emit()`（4189起，约4220起循环）的$PPP_DIAG_SIG只对最终诊断中code_ok/phase_ok项汇总。因此不能看到$SAT大残差就认定它进入最终滤波。

本轮对每期/星座/实际信号，按最终诊断的nP、meanP、rmsP，与逐星$SAT残差枚举可能子集。容差只由两端**4位小数输出舍入界限**推导，不拟合米级阈值；同时约束数量、残差和、平方和。

每组末60秒共360个码分组：**357组得到唯一匹配，3组无法重建**，无法重建的原样标记，不补齐。该结果属于“与已存最终汇总一致的接受掩码重建”，不是原位记录的逐行K或直接接受标志。

### 排除一条易误判线索：E29 C1C的大残差

首份组E29 C1C有35个可对应状态输出，其中4个大残差在全部匹配中被排除，最大约181.048m；其余31个匹配为包含，均值约+1.019m。不能把它混合后的约21.5m均值全部当成实际更新残差，更不能据此直接认定E29造成东向偏置。

### 当前更值得精确追踪：G25 C1C

首份组G25 C1C末60期在唯一匹配中**60/60均包含**：码残差均值约−7.431m、RMS约9.601m；对应1C载波仅22期vsat有效（不能以此认定码无效）。实际LOS平均东分量+0.660、北分量+0.504，该观测对东西方向有明显几何杠杆。

但仍不能写成“G25导致了+1.48m东偏”：

1. 已接受诊断行不等于具有大权重，现有B可能给了较大有效R。
2. 单个实际K行还受位置/钟差/I/模糊度及先验交叉协方差影响。
3. 现有这批日志没有保存对应行的完整pre-fit v、实际R、S及K；$SAT是验后残差，不能拿它代替innovation或直接乘LOS计算实际坐标贡献。

因此目前可收窄为：**优先核查G25 C1C及同信号组的实际有效R、E/N方向K和I/钟差吸收，而不是直接删E29、删G25或给东向坐标扣1.48m。** 本轮没有做卫星屏蔽、CN0阈值或经验处罚实验。

## 6. 结论与证据边界

已确定：当前首份诊断组主要剩余水平偏差在东向；北向对启动/状态历史更敏感。三组同时间的已用卫星几何相同；持续同号偏差和联合状态差异真实存在。E29极大状态残差不能直接当作最终参与更新证据。G25 C1C持续负残差在最终汇总重建中仍被包含，是下一步比泛化“水平差”更具体的目标。

尚未确定：哪一个观测/物理项或先验独立造成东偏，不能根据相关性、LOS或残差绝对值宣称已找到可修公式错误。未修改正式模型、R/Q/P0、坐标或参考；首份实验的偏差绝对时效未认证限制仍保留。
