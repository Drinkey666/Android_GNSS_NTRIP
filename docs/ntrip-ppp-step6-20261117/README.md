# 第六轮 M1_v3 与首个 Q6 前的东偏

## 既有证据

11:20 小米、10:04 vivo、10:04 小米和 10/31 V2 在首个 Q6 测量更新前 E 分别为 +1.173、+2.121、+1.402、+1.983 m。四包在首个 Q6 前均无 Q5 与提交成功的 PPP 更新，且日志均记录了一次成功的 SPP 启动。原 pntpos 启动路径以首槽码做加权多系统位置估计，包括通过准入的 GPS 1C、Galileo 1C 和北斗 2I。第五轮证据缺少 SPP 逐星权阵和最终正规方程，无法把 SPP 东偏定量归到某个星座或频点。后续 PPP 的增益贡献只描述相应 PPP 更新。

10:04 小米前 60 个 Q6 的 GPS 1C 按每星累计 ENU 向量模排序为 G10、G25、G28、G13、G32。G10/G25/G32 的 60 期均只有 1C，G28/G13 的 60 期均有 1C+5Q。G25 和 G28 分别贡献向东 +1.296、+1.025 m。GPS 1C 全星求和闭合于第五轮 +1.781/+3.106/−3.859 m。

## 私有实现及结果

- 参考码只运行在钟差重算后的验前对角方差。双频码使用原验前新息，单频参考码可用 GIM 时加回 I_v 与 GIM 的差。双频参考星不少于两颗时，用它们各一票取中心与 MAD，其他组用全组。至少四颗参与，尺度范围 1.2–2.2 m，有相位时门限 3.0–5.5 m，无相位时 2.0 m。
- B 的 2.5 倍与 C 的 3 倍均按规则 3 的单频 GPS 1C 范围执行。C 统计当前编辑试次参与的相位卫星数，至少六颗且已有成功 Q6 才附加 3 倍。首个成功 Q6 的规则 3 保持 1.0，规则 2 照常。无相位但仍有双频码可以触发规则 2，属于用户指定的无相位分支。
- 18 组候选实际提交的码行中，审核了 226,536 条具有双频码及相位的行，新增因子均为 1。非参考码 132,705 条也保持 1。双频码且无相位的行触发规则 2 共 9,782 次。
- 10:04 小米全段 H/U RMS 由 2.342/2.977 m 降为 A 的 2.010/2.703、B 的 1.781/2.447、C 的 1.763/2.424 m。C 仍有末段东偏 +1.383 m。C 的规则 3 分别作用于 G10、G25、G32 的 1C 码 1438、1437、1438 次。G28 的 1C 保持权重，G13 在无相位时有规则 2 动作。
- 11:20 vivo 的 A、B、C 都未触发 E27 1C 或 C19 2I 的规则 2。A 中 E27 的 362 条均有双频星定锚，最大偏离为门限的 0.994 倍。C19 没有双频定锚，最大比值为 0.926。G03 1C 的规则 2 为 64/69/70 次，B/C 的规则 3 为 362/361 次。
- A 在 11:20 两机与 10/31 V2 同时降低全段 H/U RMS，但 10:04 vivo 和 10/31 V1 的 H RMS 增大。B/C 对 10:04 小米改善更大，同时加大 10:04 vivo 的全段 H/U。10/31 V2 的 B/C 全段高程 RMS 从 0.469 m 升至 0.618/0.703 m。三档保持独立实验。
