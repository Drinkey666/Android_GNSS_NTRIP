# 因果码相一致性与独立普通Huber验证

日期：2026-10-28。当前WHU SSR原始捕获、B_VERIFIED_v2_JOSEPH、静态非组合PPP。

**授权的因果诊断和独立普通抗差试验已完成，但没有解决约9 m主要高差。末期Up由+9.042634 m变为+9.025168 m，改善0.017467 m；这不足以作为默认修复。实验保持独立、默认关闭，不降低阈值追求更小误差。**

## 1. 实际实现

### 不使用真值的因果诊断

诊断分支使用原始录流和原始TXT，锚点取程序自身首次有效PPP位置，包含该位置协方差迹。该分支没有读取用户真值经纬度、高程；已知参考仅由后续独立评估脚本计算误差曲线。

原算法更新后，私有观察器按实际SSR、天线、相位缠绕改正重建未平滑码P与米制载波L。在冻结静态锚点计算几何及VMF3预报中性延迟：

`q = P + L − 2*(range − c*sat_clock + forecast_trop)`

一阶电离层在P+L中消去。对同星座、同实际信号的连续星对取`q_i−q_j`，再减去该连续星对起点值，消去公共钟差／共享码偏差和常量模糊度。没有使用滤波估计I去构造P−L−2I，避免让待检状态先吸收异常。

每个目标需要至少3颗其他同信号连续卫星，取星对漂移的中位数。星对需3个有效样本建立历史；这是最小连续性／共识支持，不是由坐标误差选择的收敛窗口。伙伴分歧过大时放弃处罚。启动、缺测、信号切换、周跳、弧段重建、半周不确定时清理对应星对历史。

标准化漂移分母保留当前和锚点的原始码／相位基础方差、卫星产品方差，以及锚点位置不确定度随视线变化的贡献。共同恒定湿延迟误差项复用当前配置`VMF3SIG=0.15 m`。不按窗口长度假设独立并缩小方差。

该量是**时间码相一致性统计量**，不是单历元Kalman标准化新息，也没有替换B原有归一化定义。对任意空间大气变化的充分处理尚未证明。

### 普通Huber的独立接入

使用既有`PPP_HUBER_K_DEFAULT=1.5`映射：`w=min(1,1.5/|u_drift|)`，未根据真值搜索阈值。

已完成的影子诊断历元t，只能为下一历元提供权重；C入口强制检查来源时间早于应用时间，时间间隔有效。当前历元若发生弧段重建／失锁，历史处罚不应用。编辑重试读取同一证据，不推进监测历史。

只对码行构造：

`R_effective = max(R_existing, R0 / w)`

这避免把新处罚与既有legacy处罚相乘叠加，不降低原有R，不改变载波或虚拟约束R。没有新增reject、eta、Q适应或噪声方差学习。

这是**因果影子滤波器＋实验滤波器**的双分支原型：权重由未加本实验处罚的基线分支产生，实验分支不会反馈污染监测历史。离线保存权重后再回放，与这种因果双分支结构对应，不等同于已经实现并验证的Android单滤波器部署。

## 3. 可以确认的能力与限制

可以确认：判别不读真值、不读未来，不用在线I估计自证码质量；无证据／重启时不处罚；只对当前配置中少量后发漂移作软处理；关闭后输出一致。

不能确认：

- 从起始就存在的常量码参考差无法由“相对连续弧起点的漂移”识别。
- 同信号伙伴不足时必须放弃；不能用更激进阈值弥补不可辨识性。
- 一组伙伴具有共同偏差时，纯共识法可能误判少数。这一反例已作为明确限制测试保存，不能把测试通过说成质量判别全部正确。
- 静态锚点假设不适用于运动；动态模式明确不启用。静态锚点误差、未建模空间中性延迟仍可能进入诊断。
- 仅完成同一实际捕获的验证，未宣称跨手机／独立时段性能。本段没有实质改善，不将其冻结为精度候选或推广默认。

**因此，简单增加码相漂移Huber不足以修复主高差。** 后续主线必须处理初始／持续码基准项与单频电离层先验的归属和可辨识约束。当前采集包没有提供同期测量型接收机参考观测，不能据此唯一把绝对码差分配为接收机码偏差或绝对I误差。本轮不擅自加自由逐星偏差状态、不调低阈值、不放大R/Q压曲线。
