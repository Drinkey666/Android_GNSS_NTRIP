# 三项靶向码定权的隔离回放

基线已合入 WHU OSB 缓存隔离。11/14 四包沿用录制 V1，10/31 同一包分别测试 V1 和 V2。五个采集包形成六个口径，每个运行基线、M1、M2、M3、联合五种方案。全部门限和倍数在回放前固定。参考坐标只在解后计算误差及投影 K·v。

## 结果

30 组隔离回放及 6 组正式控制完成。11:20 vivo 联合全段 H/U RMS 1.187/2.289 → 1.402/1.842 m，单独 M1 1.187/2.289 → 1.160/1.955 m。10:04 双机共有 Q6 下，联合使 vivo H/U RMS 1.359/1.453 → 1.690/2.125 m、小米 2.343/2.977 → 1.833/2.581 m。10/31 末 60 秒 H/U RMS，V1 1.822/0.460 → 2.254/0.364 m、V2 1.691/0.407 → 1.778/0.093 m。联合精度取舍明显，归档为 NEGATIVE_NOT_FIX。

- 11:20 vivo 联合第 20 个 Q6 的 U 误差 -3.728 → -1.954 m。11:20 小米联合全段 H/U RMS 0.650/0.651 → 0.891/0.453 m。
- 11:20 vivo 重点星首 20 期实际 K·v 高程贡献。G03 1C -4.332 → -1.992 m，G10 1C -1.083 → -1.252 m，E27 1C -1.306 → -2.380 m，C19 2I -3.465 → -2.280 m，G25 1C +0.905 → +0.266 m。整体坐标同时受其他观测及滤波历史影响。
- 当前六口径基线 Q6 为 362、349、1786、1459、84、663。11/14 沿用 V1 且使用本次正式缓存准入，同前三轮未修复口径的数值有差异。10/31 的 V1、V2 均逐字段复现历史解，处理耗时单独记录。

## 机制与动作统计

- M1 用钟差播种后的当前位置、线视几何和 GIM 求码残差。同组中位数和 MAD 采用每卫星一票。单频性按实际验前码频槽计数，GIM 不可用时用原验前残差。
- M2 在物理 sigma 和原抗差计算完成后调整有效码方差。单频乘 3，无有效相位且非码预热乘 4，两项都满足时乘 12。支持信号、周跳、相位隔离及当前试次掩码参与有效性检查。
- M3 用未平滑改正码相和 GIM。GIM 缺失时使用原电离层模型 dion。弧锚点取首次最终提交的同槽码相值，允许距上次同弧提交 0–3 秒中的正时间间隔。周跳、换码、半周状态变化、模糊度重置、超过间隔或 GIM 来源改变后重建。弧历史只在最终提交时采样，失锁能立即清除。
- 各因子相乘。动作次数基于最终 Q6 的实际码行，均值和最大值只统计已触发行。前 20 期按各方案自身 Q6 排序，动作 CSV 也带共同前 20 期对照。双机共有窗按 GPST 周和秒匹配，末 60 秒截至该窗末个 Q6。
- K·v 使用真实求得的增益和新息。所有码、相位和约束的 ECEF 增量求和，与提交坐标减验前坐标的最大闭合差为 4.66e-10 m。
