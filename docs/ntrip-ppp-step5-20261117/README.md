# 东向偏置诊断与 M1_v2

五个正式口径复用第四轮命令、输入和产品，用同一组隔离增益观察器补录验后码残差和实际 K·v。五包执行 15 组单独星座码屏蔽，M1_v2 的两个固定门限各在六个口径运行一次，另有六组基线。共 33 组。11/14 四包沿用 V1，10/31 分列 V1 与 V2，V1 只参与 M1_v2。

## 东偏与 10:04 小米

- 10:04 小米的 GPS 1C 前 60 个 Q6 对 E/N/U 累计贡献 +1.781/+3.106/−3.859 m，全段为 +2.205/+4.556/−4.018 m。GPS 5Q 全段东向仅 +0.083 m。GPS 1C 的末 60 秒验后码残差均值为 −0.335 m。屏蔽 GPS 码后，全段 H/U RMS 从 2.342/2.977 m 降到 1.424/1.893 m，末段 E/N/U 从 +1.620/+1.300/−2.964 m 变为 +1.108/+0.366/−1.834 m。屏蔽北斗码使全段 H/U 升至 2.774/4.309 m。屏蔽 Galileo 码使 H 升至 2.984 m，同时 U 降到 2.701 m。
- 末段东偏在 15 个消融中仍为正。去 GPS 码使 11:20 vivo/小米东偏从 +1.116/+0.626 m 增至 +1.400/+0.908 m，在 10:31 V2 则降到 +0.643 m，同时末段 U 从 +0.407 上升至 +3.055 m。去 Galileo 码对 11:20 小米东偏作用最大，从 +0.626 降到 +0.297 m，但其全段高程 RMS 上升。现有数据支持不同包由不同码组和初始坐标共同形成东偏。
- 四包首个 Q6 的测量更新前已经带正 E，分别为 11:20 小米 +1.173 m、10:04 vivo +2.121 m、10:04 小米 +1.402 m、10:31 V2 +1.983 m。11:20 vivo 从 −2.462 m 起步，Q6 测量累计向东 +3.604 m，主要为北斗 2I +1.981 m、Galileo 5Q +1.362 m、IONEX +0.942 m，GPS 1C 向西 −1.151 m。
- 相位行直接累计 E 在 −0.024 至 +0.212 m，VMF3 在约 −0.005 至 +0.001 m，IONEX 的 E 符号随包改变。贡献及屏蔽试验无法把码误差的物理来源唯一分给接收机、传播环境或码相关产品。屏蔽只发生在 PPP 码方程，原码仍供 SPP、预检和平滑、模糊度播种及产品准入使用，能够保留各星座的原载波方程。消融的目标星座相位行计数在 15/15 个同 Q6 对照中完全相同。

## M1_v2

两档均只对无有效相位且非预热的码行乘 4。另在验前用 GIM 还原码偏离，GIM 缺失用原验前新息。按星座合并已去模型钟差和 RCB 的残差，每卫星一票。星座至少四颗卫星才定权。小于四星的实际信号组用星座中位数，恰为四星时用星座中位数 ±截断尺度限制信号组中心，五星及以上沿用信号组中位数。尺度限定在 1.2–2.5 m，作用于小样本中心，码偏离的绝对触发门限固定为 3.0 或 2.5 m，分别限制方差倍数为 25、36。

11:20 vivo 的 G03 1C 在两档 Huber 中分别触发 93/123 次，E27 1C 为 0/0，C19 2I 为 0/10。E27 仅命中 3 次无相位判据。10:04 小米全段实际码行 45,075 条，两档 Huber 分别触发 3,910/5,228 条，其中 GPS 1C 为 2,514/2,986 条。该包两档的全段 H/U RMS 分别为 2.045/2.822 和 1.983/2.736 m，两档末段 E 均仍大于 +1.50 m。

两档在 11:20 小米和 10/31 V1 上均提高全段 H RMS。10/31 V2 末段 E 下降约 0.28–0.30 m，N 负偏加深，H RMS 只降低约 0.07 m。2.5 m 档的 V2 全段 U RMS 还从 0.469 增至 0.631 m。M1_v2 保留为独立试验，M2 的单频三倍权与 M3 的弧起点 CMC 方案淘汰。
