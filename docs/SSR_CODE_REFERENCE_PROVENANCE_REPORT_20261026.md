# 连续码相失配已追到哪一层

## 直接结论

**本轮查明了一条具体误差链：当前 PPP 实际使用的 B1I 伪距存在滤波前的时变、非公共码参考不一致；该不一致没有由 TXT 转换或平滑递推新增，随后进入电离层、钟差、模糊度和位置。**

新证据来自同颗卫星同时记录、但当前 PPP 没有使用的 B1C 码。对 C06/C12 构造同星跨信号、再星间差，不需要固定参考坐标、预测位置、接收机钟差、ZTD、模糊度或 Kalman 增益。在 06:12:15～06:12:46 GPST：

```
D = [(P_B1I + cbias_B1I) - (P_B1C + cbias_B1C)]_C06
  - [(P_B1I + cbias_B1I) - (P_B1C + cbias_B1C)]_C12

D_start =  8.715226518 m
D_end   = 14.411283223 m
变化    = +5.696056705 m
```

对应的当前电离层状态只能解释 +0.005606086 m，GIM 中心解释 +0.000954951 m；已记录 SSR 码偏差在该窗口恒定；官方 C220/C233 的 C01/C02 天线 PCO 和 PCV 在各自卫星上完全相同。手机所报 Full/Satellite ISB 在两星之间逐历元相同，也不能解释这个星间变化。

**但是，不能将这 5.696 m 直接说成 9 m 高程误差的全部来源，也不能仅凭相对差唯一认定 C06 B1I 一个信号绝对错误。** 能确定的是这些码参考与当前已建模项不相容；精确到多路径、跟踪硬件或固件内部偏差，现有资料仍不具备独立辨识条件。本轮没有发现新的、可直接替换的 PPP 公式错误，不能用试探性修改冒充修复。

## 4. 同星双码核查为何能进一步定位

原始数据共找到 1375 条同时存在 B1I/B1C 的同星匹配对：C06 674 对、C12 701 对。B1C 只作为外部诊断通道，**没有启用到 PPP**。

重点窗口：

| 原始同星码差，m | 06:12:15 | 06:12:46 | 变化 |
|---|---:|---:|---:|
| C06：P(B1I)−P(B1C) | 9.593359 | 15.289415 | +5.696057 |
| C12：P(B1I)−P(B1C) | 2.698132 | 2.698132 | 约 0 |

两种信号的公共几何、接收机钟差、卫星钟差、对流层在同星码差中消去。再做星间差，可消去共同的接收机频间码偏差。信号传播时间稍有不同，不等于两次观测相隔数秒，不能把数米码差解释为采样错位。

实际存在且必须核对的非公共项：

### SSR 信号码偏差

复用已保存、按 CRC 验证的实际 RTCM1260 位解码，核对 mode0=B1I 与 mode10=B1C；与原生两端快照码表一致：

| 星 | B1I 加性改正，m | B1C 加性改正，m | 差，m |
|---|---:|---:|---:|
| C06 | +2.70 | +2.43 | +0.27 |
| C12 | −1.37 | +0.18 | −1.55 |

窗口内均恒定，星间码差改正为 +1.82 m，只改变差值的常量部分，不产生 +5.696 m 的变化。没有拿旧 BIA 补缺，也没有把不同格式的符号弄反。

### 天线项

使用上一轮已下载的官方带日期卫星块：C06/C220、C12/C233。每颗星的 C01/C02 PCO 和整条 NOAZI PCV 数组完全相同，因此该官方模型在任意相同视角下不会给 B1I/B1C 产生不同天线改正。当前接收机天线模型关闭。这里没有继续沿用错误旧 SVN 来证明物理项正常。

### Android 报告的 ISB

检查所报 Full ISB、Satellite ISB 的 B1I、B1C 值，在两颗星之间 32 个历元逐条相等。因此一致使用这些已报告字段，也不能消去这个星间差变化。没有依据字段名称，把它们额外叠加到已做 SSR 码偏差改正的观测中。

### 一阶电离层

`gamma=(1575.42/1561.098)^2`。该双码星间差的电离层项是 `(gamma−1)*(I_L1_slant_C06−I_L1_slant_C12)`。

- GIM 预测其变化 +0.000955 m。
- 当前估计状态对应变化 +0.005606 m。
- 实际码差变化 +5.696057 m，扣当前电离层项后仍 **+5.690451 m**。
- 如果只由一阶电离层解释，需要 31 秒内参考 L1 星间斜延迟差变化约 **309.0 m**；现有 GIM/状态及连续 B1I ADR、rate 证据没有支持这种解释。

这不把 GIM 声称为独立大气真值；只是说明现有模型中的电离层变化与码变化不相容。

B1C ADR 状态为 17、半周未解决，**不拿它当作已认证的连续相位弧段**。上述新检验只使用 B1C 码，不能借此直接将 B1C 设为更正确的正式输入。

### 6.1 为什么相当大的偏移仍能被吸收

只复用已保存八个历元的同次 H/R，追加一个明确的问题：将钟差、ZTD、逐星 I/N、RCB 等干扰列按实际单位白化、列尺度归一化后投影消去，当期方程还给位置多少独立信息？没有改变任何先验值、R、Q、P0，也没有新回放。

使用 SVD 仅确定干扰列的数值列空间，再对剩下满秩的三维位置设计矩阵做 QR。没有用伪逆返回状态，没有正则化。末历元得到：

| 当期方程集合；不含时间预测先验 | 条件形式 Up 标准差，m |
|---|---:|
| 真实 GNSS 码/相 | 353.237 |
| 加入原有电离层先验行 | 27.798 |
| 加入原有对流层先验行 | 50.219 |
| 同时加入两类原有先验行 | 12.394 |
| **实际已积累时间历史的后验** | **0.383646** |

该历元最弱位置方向的 Up 分量约 0.996。序号 129 的对应数值为 GNSS-only 183.284 m、两类先验 12.123 m、实际后验 0.630484 m。32 组信息矩阵重建检查全部通过。

**含义：** 当前瞬时 GNSS 信息在高度—大气—其他状态耦合方向很弱，紧的最终协方差主要依赖时间积累与先验；因此持续码偏移可能被历史状态吸收后，以很小的形式不确定度保留下来。这与“误差很大却没有数值崩溃、标准化新息也不一定大”相容。

**限制：** 353 m 不是实际定位误差，也不是整段 PPP 的不可观测性证明。相位跨历元连续性正是时间积累的一部分，不能因单历元弱就说相位无用。这个检查解释脆弱方向，不证明某项 Q/P0/GIM 参数错误，不为调整它们提供精度调参依据。

证据：`single_epoch_position_information.csv/.json`；工具 `diagnose_ssr_position_information.py`。与此前“固定大气中心后的码位置拟合”不同：这里将干扰状态消去，允许其变化，严格区分条件定义。

## 7. 结论分类与能否修复

**确定的代码/产品错误：**上一轮 ANTEX 把 C06/C07/C08/C12 错配旧 SVN；产品管理和旧本地文件迁移可以最小修复。本轮没有再发现新的转换、平滑或状态提交实现错误。

**确定的观测—模型不一致：**双码星间差有 +5.69 m 的时变未解释项，已存在于实际 APK 直接记录的 Android API 数据。不能再把它全部归给 Joseph 数值、SP3 插值、公共钟差、ZTD 或原始字段到 RTKLIB 的转换。

**模型适用性不足的证据：**当前 `ppp_res()` 的码方程包含几何、钟差/ISB、大气、共同 RCB 等项，没有一个独立的状态来表示该逐星逐信号码的任意时变参考偏移。现有联合估计会将可吸收部分分配到已有状态。单历元标准化残差随后可能变小，不能由“不超过既有 8σ”推断没有系统项。

**尚未唯一辨识：**该项是跟踪/接收机内部偏差、传播相关码偏移还是其他信号参考项；以及剩余全部约 9 m 的分摊。不能用当前数据证明“一个 C06 修复就能全面达到 1 m”。

因此：

- 可以修复已确认的 ANTEX 产品管理错误，不能承诺解决全部精度。
- 不能因该证据直接改默认 R/Q/P0、减小阈值、永久屏蔽 C06，或把 B1C 码直接替代 B1I；这些都不是已证实公式错误的最小修复。
- 对剩余精度问题，排查边界已经具体到**原始码参考与现有联合观测模型不相容**；当前证据不支持继续把全部大偏差叫作“卡尔曼程序把正常数据算坏了”。若要进一步选择偏移处理机制，必须承认存在这种非零、时变项并验证其可辨识性，不能假设所有有效锁定码都满足零均值独立噪声模型。
