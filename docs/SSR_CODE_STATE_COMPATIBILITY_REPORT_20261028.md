# WHU SSR：导致高差的码侧状态形状定位

日期：2026-10-28。接续2026-10-27码／相／大气分离报告。本轮沿当前小米、同一WHU实际录流、B_VERIFIED_v2_JOSEPH非组合路径继续，不重新做产品下载、CN0、P0/R扫描、星座剔除或平滑开关试验。

## 1. 新结论

**约正9 m高差主要随“可伪装成逐星电离层空间变化的非共同码差”保留。公共钟差／同频码偏差形状单独产生负高差；相对该码子空间的正交余项单独只保留约0.46 m高差。**

这里的“电离层形状”只指码观测方程的瞬时列空间，绝不等于已证明是真实电离层。将该分量与C06/C12连续相位对齐，码侧空间分量变化+6.044 m，而真实相位相对模型只变化−0.090 m，不支持将前者全部当作真实一阶电离层变化。

进一步收窄的机制是：**非共同码侧失配进入逐星电离层、位置和大气的联合估计；现有状态能在码方程中吸收这种形状，因此只依据大残差处理孤立异常，不能保证拦截该模式。** 尚未确认一个新的正式公式、索引、单位或码偏差解码错误，不能宣称正式精度已修复。

## 2. 分解对象、定义与安全边界

固定用户已确认的参考位置：30.69820588888889°、104.05203827777777°、椭球高459.813 m，同一高度。复用上一轮已验证的真实码、当前参考位置下的前向模型码、实际SSR/OSB/ANTEX及捕获大气产品。

定义每条原始码的差：`d = P_real − P_model`。只在离线诊断中构造码侧设计列：

- 每星一个`gamma=(1575.42MHz/f)^2`列，可表示任意瞬时斜向L1电离层偏移。
- 每个实际星座＋信号组一个公共截距，可表示公共钟差、ISB与共享码偏差的码侧组合。

先列归一化，再用SVD取得列空间的正交基U，仅作投影`d_compatible=U Uᵀd`，不计算任何状态逆、伪逆或物理电离层系数。`d_remainder=d−d_compatible`。

再以公共截距子空间B作嵌套分解：

`d_common = B Bᵀ d`

`d_iono_shape = d_compatible − d_common`

因而原始差严格等于三个分量之和。该划分依赖明确声明的欧氏码空间，并非生产R加权分解，也不是唯一物理误差分配。

478历元、15242条码参与分解，其中5152条是当期单频码。单频码的任意差异都可被自由逐星电离层码列表示，故其正交余项为0；这是可辨识性限制，不能据此认证它们为真实电离层。

首历元G32/1C缺少参考观察器对应行，未补造；该行在全部实验中保留真实值。其余未建模原始槽、原始载波、多普勒、质量标记均保留。正式R/Q/P0、GIM、抗差及Joseph公式和参数不变。实际有效R与拒绝可随反事实新息改变。

投影域重建误差最大1.78e−15 m，正交性误差2.23e−13 m；写回约两千万米量级原始码后的两级加和误差分别7.45e−9和1.49e−8 m。正常已知投影解析例通过。

## 5. 已区分与仍不可唯一归属

已区分：

1. 在本次数据和声明的码空间分解下，主要正高差随逐星空间码模式保留，公共模式单独产生反向高差。
2. 正交余项幅度不小，但单独回放没有保留原正9 m高差；不能仅按“无法由状态表示”的残差幅度锁定主因。
3. 驱动高差的码空间模式在代表连续弧上缺少相位支持，不能直接归为真实电离层变化。
4. 问题落在码侧模型／参考项与电离层先验及联合状态的兼容上，未发现Joseph数值修复或共同钟差幅度导致的错误。

仍不可唯一归属：

- 单频卫星静态或缓变码参考偏差与电离层绝对偏差之间的具体分配；“码列可表示”不提供独立电离层真值。
- 未知接收机／传播码偏差、卫星码产品基准或其他尚未独立标定的码改正项各占多少。
- 不同设备／时段是否具有相同模式，本轮只验证同一实际捕获，不作普适精度声明。

**后续修复落点应是对这种“有电离层形状、却缺少相位支持”的非共同码侧持续项建立可辨识的一致性处理。** 不应直接把投影量当成真实电离层写入状态、按本段真值减去码差、无约束新增逐星码偏差，或通过增大R/Q压低曲线。本轮没有实施新的自适应或抗差算法。
