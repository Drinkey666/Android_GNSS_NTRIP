# 卫星DOP、东西几何与逐星作用分析（2026-10-31）

## 结论

已补齐标准GDOP/PDOP/HDOP/VDOP/TDOP、东/北DOP、星座子集、逐星几何移除敏感性、完整时序及天空图。只读已完成三组结果，未重新解算、剔星或修改任何模型/参数。

**现有证据不支持“东向卫星几何特别差”作为持续+1.48m东偏的主要解释。** 大部分有效时段东向几何反而略优于北向；末段确实发生载波集合减少、DOP升高，但东偏早已存在，且该时刻没有相应的东向误差突跳。实际R和联合状态可观测性仍未被几何DOP认证，不能从DOP低直接宣称PPP状态模型正确。

首份启动组仍为独立诊断，偏差绝对时效未认证的边界保持，不据DOP结果将其改为手机默认。

## 数据集合与定义

使用同一10/31 11:30包、相同WGS84参考。逐期由已存$SAT方位角/高度角构造，每星一行，不把多频信号重复算成多颗独立卫星。高度角掩码沿用15°，没有重新筛选用于PPP的观测。

|集合|含义|
|---|---|
|PHASE_USED|$SAT中vsat为1的卫星去重；本轮主要几何集合|
|INPUT_CODE_CANDIDATES|原生观测存在P、已存几何可用且高于掩码的输入候选；不冒充最终接受集合|
|FINAL_CODE_RECONSTRUCTED|上轮依据最终nP/mean/RMS唯一重建的码卫星；末60秒有3期无法完整重建，明确省略，仅57期|

方位/高度角原日志保留到0.1°，因此结果是基于该输出精度的几何估计。未使用C/N0构造经验权重，也未将实际缺失的R矩阵用任意固定权重代替后称作“加权PPP DOP”。

常规单钟模型：`A=[-cos(el)sin(az), -cos(el)cos(az), -sin(el), 1]`。

另算**每个在场星座一个独立钟参数**的几何模型，避免默认所有星座钟差完全一致；其位置DOP可与此前方向几何一致性核验相互复核。多钟模型不报告冒充常规GDOP/TDOP的时钟合成量。

在单位、独立测距方差假设下，`Q=(AᵀA)⁻¹`，EDOP=√Qee、NDOP=√Qnn、HDOP=√(Qee+Qnn)、VDOP=√Quu、PDOP=√(Qee+Qnn+Quu)。实际用QR三角求解和列归一化SVD作秩判断，不用伪逆或正则化；同时复核正常方程重建残差及DOP平方恒等式。定义依据：[ESA Navipedia](https://gssc.esa.int/navipedia/index.php?title=Positioning_Error)。

**DOP是无量纲几何放大系数，不是米级误差值。** 它不包含当前滤波的R、P、电离层、模糊度、ZTD及状态间相关性，不能用来独立归因系统偏差或断言完整PPP可观测。

## 逐卫星几何作用

单颗卫星没有可独立用于三维定位的“自身DOP”。这里固定其余卫星和钟参数，仅从几何矩阵移除一行，比较EDOP/NDOP/HDOP变化；**未从Raw中删星、未重跑PPP**。

末段载波集合对东向几何较关键的包括E21、C20、E29、G28等；它们存在于集合时，几何移除后EDOP平均增加约0.107、0.097、0.092、0.076。各卫星出现期数不同，不能把该排序当作物理误差贡献排序。

G25码集合的几何移除结果：57个可重建期，EDOP平均增加**0.0444**，HDOP增加0.0415，几何不会因为删它自动改善。等权几何中“该行假设1m测距偏差→东向响应”的系数约−0.166m/m，说明存在东西几何杠杆；**它不是实际Kalman增益，不能乘上−7.43m验后残差就宣称得到G25实际东向贡献**。

G25若有偏差，即使改善几何也仍可能损害准确度；这取决于实际观测模型和权重。反之，仅因它残差大就剔除，也可能损失几何。当前没有做这种删星决策。

## 实现与验证

- 新工具`tools/analyze_whu_dop.py`，只读旧stat/observations/errors及汇总重建掩码；没有更改原有结果。
- 用现行RTKLIB `core/rtkcmn.c::dops()`（3856起）对同一已量化几何的3个真实样例交叉核验，GDOP/PDOP/HDOP/VDOP最大差约1.20e−14；独立编译小验证器，不构建APK/解算程序。
- 相同方向/高度的秩亏合成样例明确标记invalid，不输出0当成优良几何；所有有效DOP平方关系和逆重建检查通过。
- 原DOP函数在失败时返回0，本轮汇总未把这类0当作有效DOP。
- 多钟/单钟、全输入候选/最终重建/载波集合分别输出，未混为一个“当前DOP”。

## 对“原因是什么”的准确回答

本轮进一步排除了**基本联合卫星几何严重失效**以及**三种启动策略用了不同末段卫星几何**作为简单解释。尚未证明持续东偏是哪一个物理项造成。

证据更应指向观测残差与联合状态/有效权重的持续偏置，而不是继续以“东向DOP太差”作结论。下一项缺失证据仍是已收窄的G25 C1C及相关码组的真实pre-fit v、R、S、K_E/K_N，以及钟差/I/模糊度吸收；DOP不能代替这些量。本轮不据DOP改权或调参。
