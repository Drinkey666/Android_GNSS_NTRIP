## 2. 先核实状态基准：没有发现接收机码偏差索引错误

实际代码：

|位置|实际含义|
|---|---|
|`core/ppp.c:261 ppp_ifb_index()`|GPS/GAL 5Q 与 BDS 7I/5P/1P 分别有公共接收机码偏差状态；GPS/GAL 1C、BDS 2I 作为各系统参考码。|
|`:2585 uddcb_ppp()`|初始化及传播上述接收机状态，不给参考码重复建状态。|
|`:3610`、`:3648`|实际信号频率决定 `gamma=(fL1/f)^2`；码电离层系数为 `+gamma*mapf`，相位为负号。|
|`:3651–3672`|码行加入对应 RCB，相位行加入对应卫星/频率 N；钟差/ISB、ZTD 和几何共同参与。|
|`:3868`、`:3884`|GIM 虚拟行约束垂直 I，H[II]=1，R 来自原产品方差、时间预算和既有处罚。|

对保存的8个实际更新，逐行核对实际信号、I/RCB/N/clock 状态列；同星不同频率的 I 映射一致。以下联合变化按每星 mapf 构造：

```
ΔI_vertical_s = δ / mapf_s
Δclock_system = -gamma_reference * δ
ΔRCB_f       = (gamma_reference - gamma_f) * δ
ΔN_s,f       = (gamma_reference + gamma_f) * δ
```

它保持该星座所有真实码/相位方程不变。GPS 公共钟变化同时由其他系统 ISB 抵消，不误改其他系统方程。

23 个星座/更新检验中，`max|H_GNSSᵀ g|=4.44e−16`。因此基准自由度真实存在；**这不是新增代码错误，物理 GIM 和时间先验可以约束它。** 也不能因为存在自由度，就直接增一个与已有状态重复的公共码偏差。

## 3. 同一预测下，共同偏移并不解释大的高度变化

使用同一次 P−、H、v、R，给北斗 GIM 行增加未知公共斜向偏移 beta，即这些先验行的 `B_s=1/mapf_s`，真实 GNSS 行 B=0：

```
S = Hᵀ P− H + R
beta = (Bᵀ S⁻¹ B)⁻¹ Bᵀ S⁻¹ v
Δx_extra = -K B beta
```

只做直接求解，无伪逆/正则化。在7个有北斗先验的保存更新中，局部 Up 改变约 −5.0～−7.2微米。不能用这个小局部量排除历史反馈，所以又完成整段共同方向实验，结果见下表。

补齐精确 mapf 的独立观察器还发现：部分 GIM 行对应本次没有真实 GNSS 行的卫星。其映射不能从 GNSS H 恢复，故新增只读原生记录，而不是猜高度角。记录所有试算的实际 map、I、先验及方差后，按最终提交行对齐；701历元输出、状态、观测及改正日志均原样。

## 4. 用正交投影区分两类先验信息

对目标星座每个 GIM 先验，原标准差 sigma_s，定义白化方向：

```
b0_s  = 1 / (mapf_s * sigma_s)               # 共同斜向 I 偏移
raw_s = sin(elevation_s)/(mapf_s*sigma_s)   # 高度角相关的空间变化
b1    = raw - b0 * (b0ᵀraw)/(b0ᵀb0)        # 去掉共同方向后的几何对比
```

Householder 正交变换将待删方向旋转到第一轴，保留其余对比行；故并非把某颗卫星整个剔除，也非按真值优化权重。`b1` 是高度角相关的先验方向，**不等于所有观测/状态耦合下精确、唯一的高度误差模态**，还可能与 ZTD 等状态耦合。

混合先验行明确标记为 `IONO_PRIOR`、sat=0、source=-1，不伪装成某颗手机信号。原始先验时间记账保持，初始化不改。本方法只是识别实验，不是一个经过独立标定、可以直接上线的大气相关模型。

## 6. 双频码差闭合：一个公共 RCB 不能吸收全部跨卫星差异

使用已经保存的实际选用码、原SSR/天线改正、当前GIM及提交状态；不重放，不用CN0筛行。对于同一星同一期两种真实信号：

```
apparent_DCB_s = (P_f_corrected - P_ref_corrected)
                - (gamma_f - gamma_ref) * mapf_s * I_GIM_s

apparent_DCB_s - RCB_est
    = (gamma_f-gamma_ref)*mapf_s*(I_est_s-I_GIM_s)
      + (postfit_code_f - postfit_code_ref)
```

几何、钟差、对流层和坐标从码差中消去。此处回代估计 I/RCB 是核实误差吸收和实现闭合，**不是用滤波自己的状态证明物理模型正确**。

共4265个已保留码对候选：9对缺少当前初始化期GIM行、9对在已知Q5钟跳期缺少旧几何观察器记录，余下 **4247对全部核算**，未按残差大小删对。

|系统/信号对|闭合码对数|最大回代误差|同一期不同卫星表观DCB极差中位数|P95极差|
|---|---:|---:|---:|---:|
|GPS 1C+5Q|952|2.04微米|4.338m|18.019m|

这些“表观DCB”包括真实接收机偏差、差分电离层预报误差、信号/改正误差，并非独立校准的硬件偏差。其星间差异不能被现有单个公共RCB完全吸收。北斗甚至不是该幅值最大的系统，却对高度影响最明显，**偏差幅度和几何/先验耦合必须一起考虑**。

对全部1430个星座/历元的GIM验后残差，北斗共同斜向方向解释的加权能量中位数仅0.60%，加入高度角项约23.21%；Galileo对应约45.91%，但控制回放却变差。不能把这些描述性比例当因果效应或独立样本显著性。

## 7. 剩余偏差与形式不确定度仍不匹配

没有完整实验后验交叉协方差时，不把XYZ对角线直接旋转成Up方差。利用任何PSD矩阵必满足的保守界限：

`sigma_Up <= Σ |Up_axis_i| sigma_XYZ_i`。

计算时为CSV每项sigma另加0.5微米舍入余量。修正ATX+北斗方向实验末期Up约5.038m，而形式Up标准差的**最大可能值**约0.4342m，误差至少为该标准差的11.60倍。各组最后60s均在 `|Up|>1.96*该上界` 外。

这不是假定时间独立的95%覆盖统计检验，也未重新证明参考点测量精度；是在接受用户真值的条件下说明：即使某个诊断曲线改善，现有形式协方差仍未描述持续偏差。不能把此实验当成已经统计一致的候选版本。

## 8. 本轮判断及是否能正式修复

**已明确的来源层次**：北斗码与物理GIM先验的跨卫星几何信息存在联合不一致，通过I—钟/RCB—N—ZTD—高度状态持续分配；其中一个高度角相关先验方向的轨迹效应约3.1m，两个天线产品下均可复现。共同码偏差自由度和没有当期GNSS行的先验，不是本次大差异的主要单独来源。

**已排除的具体猜测**：保存更新中的I频率/符号/RCB/N列不匹配；把参考码再建一个公共状态就能修好；无GNSS行先验造成约4m；旧天线身份单独解释该3m效应；各星座统一放松先验即可提升精度。

**没有证明的部分**：不能由删除一维先验后更近参考，认定它本来就是错误信息。仍无法唯一分开逐星码参考误差、差分GIM预报误差及其相关性/时间模型失配。GIM同源格网和时间重复的误差在现有对角先验模型中没有完整空间—时间协方差，但本实验没有标定那份真实协方差。

本轮**没有新发现可直接改正式公式的确定代码错误**。下一次若实施模型修复，应在 `ionex_vertical_prior()` / `ppp_res()` 的先验相关性及其与RCB物理基准兼容性上给出依据，不能直接删北斗、把某个sigma调大、增加不可辨识的逐星码偏差，或将本实验的无限不确定度方向设为默认。仍有约5m残差、水平退化和形式方差失配，不能验收为精度已解决。
