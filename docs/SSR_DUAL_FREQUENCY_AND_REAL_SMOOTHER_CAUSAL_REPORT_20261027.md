## 2. 双频闭合的物理含义

米制观测记为：

`P_f = common + gamma_f I + B_f + code_error_f`

`L_f = common - gamma_f I + N_f + phase_error_f`

构造 `Q_s=(P_f-P_1)+(L_f-L_1)`，几何、公共接收机/卫星钟差、对流层以及一阶电离层均消去。实际SSR码偏差、卫星/接收机天线项和相位缠绕仍按已记录原式处理。随后同星座同频对作星间差，再沿同一连续弧作时间差：共享接收机频间偏差即使随时间变化也消去，常量模糊度消去。

剩余变化不能由上述状态的无噪声方程重新分配消除；但可以来自码/相测量误差、时间相关的非共同频间项、未建模频率相关物理项等。**非零闭合不等于已经证明观测无效，也不唯一证明接收机硬件故障或实现错误。**

代码对应：`core/ppp.c:1151 corr_meas()`、`:3402 ppp_res()`；诊断代数遵从实际频率及米制相位。没有将组合观测送入正式非组合PPP。

## 4. 当前可以排除与不能排除的内容

**本轮有数据支持的排除：**

1. 同一连续弧内的双频星间码相闭合变化，不是仅调整位置、公共钟差、ZTD、一阶电离层、常量模糊度或共同RCB就能解释的量；不能继续笼统归因于“非组合电离层没有消除好”。
2. 原伪距平滑均值传播不是本次最终约9 m高差的主要来源。它对完整轨迹有影响，但绕过后大高差仍在。
3. 已知C19/C20弧段异常不能单独指认最终正高差来源，实际更新方向反而向下。

**尚未被证明：**

- 这些时变非共同码相项的唯一物理来源；不能在码硬件、传播误差、相位参考或未建模项之间强行分摊。
- 特别是主要固定位置ZTD更新来源C06/C12等单频观测的独立电离层/码偏差分离，本轮双频相位覆盖不能替代它。
- 全部9.04 m到底各来自多少模型偏差、外部先验误差或相关观测误差；原有GIM空间方向实验只证明敏感性，不是唯一因果分解。

**剩余最有依据的根因类别是非共同、相关的码相/参考失配与大气及位置状态的联合吸收；目前未确认新的符号、单位、索引或公式错误。** 这一类别不足以授权盲目给每星增加可自由漂移的码偏差状态：它与电离层/模糊度存在不可辨识性，需要独立约束和验证。也不足以把8σ、增大R或删星当作已验证修复。
