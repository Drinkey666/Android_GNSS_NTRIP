## Part A · 物理项精确拆解与启动门限审计（LOCATING_EVIDENCE）

直接复用 Step 9 的 115 条接纳实测行与首个 Q6 前 PPP 观测/大气快照，按固定线性化参照和 Oaxaca–Blinder 对称分解验证：

### 1. 双机同秒共视星启动东向差物理拆解

- **核心物理结论**：同秒共视条件下，两部手机使用的卫星钟差、WHU SSR 码偏差（OSB）、广播电离层和 Saastamoinen 对流层相对差几乎完全相消（东向贡献 `0.000 m`）。
- **`11:20` 双机 `3.635 m` 启动东向差**：由共视星观测值差异贡献 `+4.904 m`（其中纯手机端原始测码组内相对差占 `+4.252 m`），C/N₀ 权阵差异仅占 `+0.376 m`，非共视星（主要为 vivo 独有 `E07` 单星推东 `+1.637 m`）抵消 `−1.644 m`。单星 `G25 1C` 上两机原始码组内相对差高达 `−21.311 m`，直接贡献了 `+3.300 m`（含权阵差共 `+3.327 m`）的东向分化；`G03 1C` 相对差 `+7.418 m` 贡献 `+1.088 m`。
- **`10:04` 双机 `−0.718 m` 启动东向差**：共视观测差贡献 `−0.721 m`（原始码相对差 `−0.459 m`），权阵差 `−0.153 m`，小米独有 `E30` 贡献 `+0.156 m`。

### 2. SPP 广播大气 vs PPP 首期 GIM/VMF3 推力与启动门限

- **大气模型差的作用边界**：
  - `Saastamoinen` 与 `VMF3` 对流层差对六组启动东偏的影响极小（单星座组均 `≤ 0.017 m`）。
  - `SPP 广播电离层` 与 `PPP 首期 CODE GIM` 的差异在 `11:20` 时段对 GPS/GAL 存在约 `+0.34 ~ +0.44 m` 东向推力（`11:20 小米` GPS `+0.371 m`、GAL `+0.409 m`、BDS `−0.218 m`，净 `+0.562 m`），但在 `10:04` 与 `10/31` 时段单组不超过 `0.18 m`。
  - 扣除广播电离层与对流层模型差后，各包主导东偏依然留存：`11:20 小米` GPS `1C` 留存 `+0.979 m`、`11:20 vivo` GPS `1C` 留存 `−3.313 m`、`10:04 vivo` BDS `2I` 留存 `+1.926 m`、`10/31 V2` GAL `1C` 与 BDS `2I` 分别留存 `+1.260 m` 和 `+0.620 m`。这证明启动东偏的主因是首槽原始伪距与在轨/OSB 基准上的**星间相对残差**，而非对流层或 Klobuchar 广播电离层模型本身。
- **为何启动质控（`startup_fde` / `STARTQC`）未触发**：
  - `startup_fde` 要求同时满足 `|postfit_nl| > 30.0 m` 且杠杆修正标准化残差 `z > 6.0`。六组最大残差为 `11:20 vivo` `G25 1C` 的 `11.15 m`（`z = 3.24`），其余五组最大仅为 `2.69–6.75 m`（`z = 1.33–2.34`）。
  - `precheck_startup_code_ppp` 门槛为 `max(30.0 m, 6×MAD, position_gate)`。六组最大偏离与门槛比值为 `0.161–0.244`（小米各包）和 `0.625`（`11:20 vivo` `G25 5Q/1C` 差 `−18.761 m` vs `30.00 m` 门限），均远低于现有 30 m 硬门槛。

## Part B · 泛在手机非组合提精隔离实验（NEGATIVE_NOT_FIX）

在保留全部 6 组正式基线的基础上，构建私有 `step10_probe.exe` 分别测试：
- **`O1_df_iono_anchor`**：用同历元 `≥3` 颗双频有效星的 `x[II(s)] − I_GIM(s)` 中位数 $\delta I_{\text{df}}$（限幅 `±2 m`）修正单频星 GIM 先验中心，收紧单频星先验标准差至 `0.60 m`（双频保持 `1.50 m`），单频星电离层过程噪声标准差乘 `0.5`，并关闭单频星 `ION_CONSTR_ROBUST` 弱化膨胀。
- **`O2_arc_code_info`**：在 `DOPPSM=0.90` 启用且存在已激活、未重置、无周跳连续载波相位弧（弧连续锁定计数 `arc_lock ≥ 1`）时，将平滑伪距基础方差乘以有界去重倍率 $f_{\text{info}} = \min(6.0, 1.0 + 5.0\min(1.0, \text{lock}/10.0))$，同时保留膨胀前原物理 `sigma0`/`z0` 不变。
- **`O3_joint`**：同时启用 `O1 + O2`。

### 1. 关键结果与跨包权衡

完整六包四方案全指标见 [TERMINAL_TABLES.md](TERMINAL_TABLES.md) 与 [partB_accuracy_summary.csv](partB_accuracy_summary.csv)：

- **`O1` 的跨包表现（高程局部有效、跨日存在取舍）**：
  - 在 `11/14` 四组数据上，`O1` 稳定降低高程 RMS：`11:20 小米` 全段 U RMS `0.651 → 0.476 m`（末 60 s `0.333 → 0.125 m`）、`11:20 vivo` `2.289 → 2.034 m`、`10:04 小米` H/U 同步降至 `2.300/2.853 m`（原 `2.342/2.977 m`）、`10:04 vivo` U `1.390 → 1.285 m`。
  - 但在 `10/31` 两组上出现明显高程反退：`10/31 V1` 末 60 s U RMS `0.460 → 1.063 m`（尽管全段 H `1.849 → 1.703 m`）；`10/31 V2` 全段 H/U 从 `1.864/0.469 m` 反退至 `1.942/0.923 m`（末 60 s U `0.407 → 1.245 m`）。原因为固定 `0.60 m` 先验且关闭 `ION_CONSTR_ROBUST` 后，GIM 在 `10/31` 的局部偏差被直接强加到单频卫星高程分量上。
- **`O2` 与 `O3_joint` 的跨包表现（揭示“有偏初值锁定”负效应）**：
  - 在小米部分长弧段改善显著：`10:04 小米` 全段 H `2.342 → 2.213 m`（前 20 期 `2.839 → 2.442 m`，前 60 期 `2.738 → 2.268 m`，末 60 s H/U `2.077/2.964 → 1.977/2.546 m`），`10/31 V2` 全段 H/U `1.864/0.469 → 1.769/0.454 m`（末 60 s U `0.407 → 0.204 m`）。
  - 但在 `11:20 vivo` 和 `10:04 vivo` 上明显反退：`11:20 vivo` 全段 H/U `1.187/2.289 → 1.272/2.707 m`，`10:04 vivo` 全段 H/U `1.340/1.390 → 1.478/2.463 m`。
  - **机制归因**：当首历元（`lock=0`）或周跳后用带米级偏差的伪距播种了浮点模糊度 $B_f$ 后，如果在后续连续历元直接放大平滑伪距方差（`O2`），会削弱后续新鲜无偏伪距对初始有偏模糊度的纠偏拉力，反而把首期误差“锁定”更长时间。
- 鉴于 `O1`、`O2`、`O3_joint` 均存在跨包精度反退，三者统一归档为 `NEGATIVE_NOT_FIX`，不合入正式代码。
